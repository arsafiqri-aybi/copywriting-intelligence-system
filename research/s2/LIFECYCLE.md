## Evidence cycle

research question
→ targeted retrieval
→ source screening
→ atomic claim extraction
→ construct mapping
→ contradiction/null search
→ measurement/operationalization check
→ transport/boundary check
→ promote / provisional / reject / merge
→ dependency update
→ targeted regression

## Breadth-first rule

During early S3, every core and module receives minimum viable evidence coverage before any one module is deeply saturated.

Deepening priority is determined by runtime criticality, uncertainty, cross-core centrality, evidence conflict, measurement risk, copywriting impact, and downstream dependency count.

## No fake numerical certainty

Do not create universal node weights from citation counts, subjective confidence, or effect sizes measured on incompatible outcomes. Runtime calibration is a separate S7 activity.
