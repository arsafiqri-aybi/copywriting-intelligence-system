# Market-to-Mechanism Inference Policy

1. Never convert a commercial label directly into a scientific node.
2. Observed/reported facts outrank model-inferred assumptions.
3. A customer quote is evidence about what was said in that context, not a validated latent-state measurement.
4. A platform metric is an outcome/proxy, not a direct psychological-state measure unless separately validated.
5. Feature, benefit, value proposition, offer, objection and CTA are different object types.
6. Every mechanism activation must preserve alternative explanations when material.
7. Provisional nodes/edges may guide questions and experiments but cannot be presented as settled laws.
8. No market-to-mechanism mapping carries an empirical effect size.
9. Runtime priority scores, if later introduced, must be explicitly labeled architecture/calibration parameters.
10. If evidence is insufficient, the correct output is a question, hypothesis, non-edge or experiment—not fabricated certainty.

## Epistemic precedence

1. randomized_or_strong_behavioral_evidence
2. validated_instrument_or_direct_observation
3. repeated_customer_research
4. single_customer_report
5. user_brief_assertion
6. market_framework_label
7. model_inference
