# Measurement, Experiment & Feedback

This layer learns from observed behavior without confusing platform metrics with latent psychological mechanisms.

## Core boundary

- Impressions are exposure, not attention.
- View duration is not validated sustained attention by default.
- CTR is behavior, not a persuasion mechanism.
- Conversion is a commercial outcome, not proof of a theory.
- Unsubscribe is behavior, not direct measurement of reactance.
- Campaign observations update bounded runtime hypotheses first.
- Scientific claims still require the research promotion lifecycle.
