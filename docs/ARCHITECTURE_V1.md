# Architecture v1

## L0 — Real-world context

Inputs include objective, audience, situation, product, market, channel, brand, constraints and available evidence.

## L1 — Market & Value Model

Represent:

- customer current state;
- desired state/outcomes;
- jobs/problems/desires;
- alternatives and competition;
- product features and mechanisms;
- functional/emotional/identity benefits;
- category expectations;
- differentiation and positioning;
- perceived value and perceived cost;
- pricing perception;
- offer architecture;
- risk and friction;
- switching barriers;
- objections;
- reason-to-believe;
- customer language.

This layer feeds the core graph. It is **not** Core 8.

**Current module count: 56 provisional modules.**

The module count is not a target to protect. Modules may split, merge, move or be rejected after taxonomy and construct-boundary research. The seven top-level cores remain protected unless explicit re-plan is justified.

## L3 — Cross-core scientific network

Nodes may:

- cause increase/decrease;
- support;
- inhibit;
- bias;
- enable;
- compete;
- update;
- reinforce;
- mediate;
- moderate;
- predict;
- associate;
- form feedback links.

Every material edge must preserve mechanism, causal status, evidence, moderators, boundary conditions, transport limits, uncertainty and lifecycle status.

All **21 unordered core pairs** must eventually be audited. An audited pair may legitimately contain no direct scientific edge.

## L4 — Message synthesis

Infer:

- communication objective;
- dominant mechanisms;
- audience state;
- message hypothesis;
- claim;
- benefit/value;
- proof;
- framing;
- emotion;
- objections;
- sequencing;
- language;
- CTA.

Only then generate copy.

## L5 — Channel adapters

At minimum:

- advertising;
- landing pages;
- sales pages;
- ecommerce/product pages;
- email;
- social media;
- short-form video;
- long-form video/scripts;
- messaging/WhatsApp;
- UX/product copy;
- packaging;
- SEO/search.

Channel adapters modify format constraints, not core psychological science.

## L6 — Output & observation

Copy is exposed in a real or simulated context. Collect behavioral and qualitative observations without assuming they uniquely identify latent psychological states.

## L7 — Measurement, experiment & feedback

```text
COPY
→ EXPOSURE
→ OBSERVATION
→ MEASUREMENT
→ ALTERNATIVE EXPLANATIONS
→ EXPERIMENTAL INTERPRETATION
→ BOUNDED UPDATE
```

Feedback may update audience hypotheses, market estimates, channel priors, message hypotheses, runtime heuristics and calibrated parameters.

Scientific knowledge changes require evidence appropriate to the scientific claim.
